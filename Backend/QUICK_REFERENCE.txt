📍 ENDPOINT
──────────────────────────────────────────────────────────────────────
GET /job-titles/search?q={query}&limit={limit}


🎯 SEARCH STRATEGIES
──────────────────────────────────────────────────────────────────────

1️⃣  BROAD SEARCH (Exploratory)
    Trigger: Query < 8 chars OR 1 word
    Returns: ALL matching titles
    Example: "dev" → 11 results
    
2️⃣  EXACT MATCH (Highest Priority)
    Trigger: Multi-word query with exact DB match
    Returns: Only the exact title
    Example: "Software Engineer" → ["Software Engineer"]
    
3️⃣  FUZZY MATCH (Semantic)
    Trigger: Multi-word query, no exact match
    Returns: Top 5 similar titles (by similarity score)
    Example: "Senior Software Developer" → 5 similar titles
    
4️⃣  TOKEN MATCH (Fallback)
    Trigger: Fuzzy returns nothing
    Returns: Titles containing ALL query words
    Example: "Backend Node Developer" → titles with all 3 words


📊 RESPONSE FORMAT
──────────────────────────────────────────────────────────────────────
{
  "query": "dev",
  "strategy": "broad_search",
  "match_type": "partial",
  "results": ["Java Developer", "Full Stack Developer", ...],
  "count": 11
}

💡 DESIGN RULES
──────────────────────────────────────────────────────────────────────
✓ Short queries = exploration mode
✓ Exact match always wins
✓ Fuzzy limited to top 5 (prevent overwhelm)
✓ Never return irrelevant roles
✓ Never invent new titles
✓ All results from database only

🎨 FRONTEND INTEGRATION
──────────────────────────────────────────────────────────────────────
import { useJobTitleSearch } from './hooks/useJobTitleSearch';

function SearchBar() {
  const { query, setQuery, results, loading } = useJobTitleSearch();
  
  return (
    <div>
      <input value={query} onChange={e => setQuery(e.target.value)} />
      {loading && <Spinner />}
      {results.map(title => <div key={title}>{title}</div>)}
    </div>
  );
}
